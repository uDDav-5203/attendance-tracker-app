# 📊 Отслеживание посещаемости

Полнофункциональное веб-приложение для отслеживания посещаемости с аналитикой и управлением участниками.

## ✨ Особенности

### 🎯 Основной функционал
- **Отметить посещаемость** для каждого участника с тремя вариантами:
  - ✓ Присутствует (зеленый)
  - ✗ Отсутствует (красный)
  - ⚠ Уважительная причина отсутствия (оранжевый)

- **Выбор даты**: Легко переключайтесь между датами для отметки посещаемости
- **Сортировка**: Сортируйте участников по:
  - Имени (А-Я, Я-А)
  - Посещаемости (чаще всего отсутствовали, чаще всего присутствовали)

### 👥 Управление участниками
- Добавляйте новых участников (по умолчанию 13 человек)
- Изменяйте имена участников
- Удаляйте участников из списка
- Все данные сохраняются автоматически

### 📈 Аналитика
- Выбирайте период для анализа (от и по датам)
- Просматривайте статистику для каждого участника:
  - Количество присутствий
  - Количество отсутствий
  - Количество уважительных причин
  - Процент посещаемости (визуальная полоса)

- **Топ 3 рейтинги:**
  - 🔴 Топ 3 с наиболее частыми отсутствиями
  - ⚠️ Топ 3 с наиболее частыми уважительными причинами

### 🎨 Дизайн
- **Темная тема** в стиле Google (Material Design Dark)
- Адаптивный интерфейс (работает на мобильных устройствах)
- Плавные переходы и анимации
- Интуитивные кнопки и элементы управления

## 🚀 Использование

### Открыть приложение
1. Откройте файл `index.html` в веб-браузере
2. Приложение готово к использованию!

### Как использовать

#### Отметить посещаемость
1. Выберите дату в поле "Дата"
2. Нажимайте кнопки для каждого участника:
   - ✓ (зеленая) - участник присутствовал
   - ✗ (красная) - участник отсутствовал
   - ⚠ (оранжевая) - уважительная причина
3. Данные сохраняются автоматически

#### Добавить участника
1. Введите имя в поле "Введите имя участника"
2. Нажмите "+ Добавить"

#### Изменить имя участника
1. Найдите участника в списке "Управление участниками"
2. Нажмите "Изменить"
3. Введите новое имя

#### Просмотреть аналитику
1. Выберите период (от и по даты)
2. Нажмите "Создать отчет"
3. Просмотрите таблицу статистики и рейтинги

## 💾 Сохранение данных

Все данные сохраняются в локальном хранилище браузера (Local Storage). Это означает:
- ✅ Данные сохраняются автоматически
- ✅ Никаких серверов не требуется
- ✅ Данные остаются при закрытии браузера
- ⚠️ Данные специфичны для браузера и устройства

```css
    --error-red: #ea4335;       /* Отсутствует */

```

## 🐛 Решение проблем

### Данные не сохраняются
- Проверьте, что Local Storage не отключен в браузере
- Проверьте режим инкогнито/приватного просмотра (данные не сохраняются)

### Приложение выглядит странно
- Попробуйте очистить кэш браузера (Ctrl+Shift+Delete)
- Убедитесь, что вы используете современный браузер

### Хочу экспортировать данные
- Откройте Developer Tools (F12)
- Перейдите на вкладку Console
- Введите: `copy(JSON.stringify(localStorage))`
- Данные скопированы в буфер обмена
